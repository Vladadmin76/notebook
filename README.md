# Блокнот: Telegram-бот и мини-приложение для заметок и напоминаний

Человек пишет или наговаривает боту, бот исправляет текст, делит сообщение на отдельные заметки, раскладывает их по папкам и напоминает в нужное время. Всё это же можно смотреть и править в мини-приложении внутри Telegram. Работает для многих людей сразу, вход только по приглашению. Интерфейс на русском.

Один Cloudflare Worker делает всё: принимает сообщения Telegram, раз в минуту рассылает напоминания и раздаёт приложение. Своего сервера нет. Хостинг на бесплатном тарифе Cloudflare, платить нужно только за запросы к DeepSeek.

## Что умеет

**Бот**
- Любое сообщение (текст или голос до 180 секунд) разбирается DeepSeek: исправление орфографии, деление на отдельные дела, выбор папки, поиск времени для напоминания.
- Покупки собираются в списки по магазинам: «в Костко молоко и яйца, в Walmart батарейки, ещё сметану» раскладывается по спискам Costco, Walmart и «Без магазина» (название узнаётся по звучанию, новый магазин сам становится избранным). `/buy` показывает кнопки со списками, `/buy Costco` открывает нужный; фразы «покажи список для Costco» и «покажи все продукты» бот узнаёт сам. Галочки «куплено».
- Напоминания: «завтра в 9», «через 3 минуты», «каждый понедельник и среду в 10:30», «раз в две недели по пятницам». Кнопки «Готово», «Отложить на 1 час», «До завтра 9:00».
- Только ссылка в сообщении попадает во «Входящие»; кнопки «Куда поместить», «Добавить комментарий». Пока во «Входящих» что-то лежит, раз в сутки в 12:00 по местному времени бот называет, сколько ссылок лежит (окно 12:00-14:00 на случай сбоя таймера; ссылка, добавленная позже, ждёт следующего дня).
- Команды: `/folders`, `/list`, `/buy`, `/reminders`, `/cancel`, `/help`.

**Приложение** (кнопка «Блокнот» в чате): папки и поиск, правка заметок, «Задачи» с отметкой «выполнено» и серой полосой-разделителем, список покупок, календарь, редактор напоминаний (повтор по дням недели), экспорт в календарь (`.ics`, Google Календарь), корзина (значок рядом с ⚙️: пустая или полная), магазины (избранные магазины = списки покупок), настройки (тема авто/светлая/тёмная, часовой пояс), генератор паролей. Новая заметка в приложении пока не создаётся (только через бота).

**Администратор** (по Telegram ID из секрета): приглашения, список людей, блокировка, удаление. В приложении панель открывается удержанием значка ⚙️ сверху справа в течение 2 секунд; в боте: `/invite`, `/revoke`, `/users`, `/block`, `/unblock`, `/remove`.

## Как устроено

```
Telegram ──(webhook)──▶ /tg/webhook ─┐
cron-job.org ─(раз в минуту)▶ /cron/tick ├─▶ Cloudflare Worker ──▶ D1 (база notes_db)
Мини-приложение ──▶ /api/*, страницы ─┘            │
                                                    ├──▶ DeepSeek (текст, папки, даты)
                                                    └──▶ Groq Whisper (голос в текст)
```

- **Вход в приложение без паролей и cookie.** Telegram передаёт приложению подписанные данные (`initData`), Worker проверяет подпись по токену бота и срок (24 часа). Подделать Telegram ID без токена бота нельзя.
- **Приглашения** одноразовые: ссылка `t.me/<бот>?startapp=КОД`. Человек открывает её, называет имя, и ссылка гасится. Админ может отозвать приглашение до использования.
- **Время** в базе всегда UTC; повторы считаются в местном времени человека, поэтому 9:00 остаётся 9:00 при переходе на летнее время.
- **Время даёт код, а не модель.** DeepSeek только понимает смысл фразы, даты и сроки считает `luxon`.

### Структура репозитория

| Путь | Что там |
|---|---|
| `wrangler.toml` | имя Worker'а, база D1, домен, статика приложения |
| `migrations/` | схема базы (применяется при каждом деплое) |
| `src/index.js` | маршрутизация, вход по подписи Telegram, заголовки безопасности |
| `src/bot.js` | бот: команды, заметки, голос, кнопки, ссылки, покупки |
| `src/appapi.js` | интерфейс приложения: папки, заметки, календарь, напоминания, покупки, `.ics` |
| `src/deepseek.js`, `src/groq.js` | обращения к DeepSeek и Groq, проверка их ответов |
| `src/reminders.js`, `src/timeutil.js` | рассылка напоминаний, повторы, пересчёт времени |
| `src/ics.js`, `src/auth.js`, `src/db.js` | файл календаря, проверка подписи Telegram, запросы к базе |
| `src/trash.js` | корзина: просмотр, возврат, окончательное удаление, уборка по сроку |
| `src/stores.js` | перечень магазинов и узнавание названий по звучанию |
| `src/config.js` | настройки: лимиты, стартовые папки, час напоминания о «Входящих» |
| `public/` | приложение (чистый HTML, CSS, JS без фреймворков) |
| `scripts/*.mjs` | сквозные проверки на запущенном `npm run dev`: защита и изоляция (`check:isolation`), корзина (`check:trash`), магазины (`check:stores`) |
| `test/` | автотесты логики (`npm test`) |

## Развёртывание с нуля

Проверенный порядок. Всё можно сделать с телефона через сайт Cloudflare, терминал не нужен.

### 1. Бот
В Telegram откройте @BotFather → `/newbot` → имя «Блокнот» и username (должен кончаться на `bot`). Сохраните **токен**. Свой Telegram ID узнайте у @userinfobot.

### 2. База
В панели Cloudflare: Storage & Databases → D1 → Create Database, имя `notes_db`. Скопируйте ID базы. В `wrangler.toml` впишите `database_id` и `BOT_USERNAME` (без `@`). Домен приложения в `routes` должен быть в этом же аккаунте Cloudflare.

### 3. Деплой из репозитория
Workers & Pages → Create → Connect GitHub → репозиторий. Параметры сборки:
- **Project name:** `notes-bot` (должно совпадать с `name` в `wrangler.toml`);
- **Deploy command:** `npx wrangler d1 migrations apply notes_db --remote && npx wrangler deploy`. Так таблицы создаются и обновляются при каждом деплое.

С компьютера то же самое: `npm install`, `npx wrangler login`, `npm run db:migrate`, `npm run deploy`.

### 4. Секреты
Откройте Worker → Settings → **Runtime** variables and secrets (не «Build»!) → Add variable → тип **Secret**:

| Имя | Значение |
|---|---|
| `TG_BOT_TOKEN` | токен от @BotFather |
| `TG_WEBHOOK_SECRET` | случайная строка из латинских букв, цифр, `_` и `-` (другие символы Telegram не принимает) |
| `CRON_SECRET` | другая случайная строка |
| `ADMIN_TELEGRAM_ID` | ваш Telegram ID, цифры |
| `DEEPSEEK_API_KEY` | ключ с platform.deepseek.com (модель `deepseek-flash`) |
| `GROQ_API_KEY` | бесплатный ключ с console.groq.com (модель `whisper-large-v3-turbo`) |

Секреты применяются примерно за минуту. В `wrangler.toml` включено `keep_vars = true`: без этого сборка из GitHub стирала секреты, добавленные в панели.

### 5. Webhook
Один раз откройте в браузере (подставьте свои значения, без пробелов и скобок):
`https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://<ваш-домен>/tg/webhook&secret_token=<TG_WEBHOOK_SECRET>`
В ответе должно быть `"ok":true`.

### 6. Мини-приложение в Telegram
- @BotFather → `/mybots` → ваш бот → Bot Settings → Configure Mini App → Enable Mini App → адрес `https://<ваш-домен>`. Это включает ссылки приглашений.
- Кнопка «Блокнот» внизу чата: откройте
  `https://api.telegram.org/bot<ТОКЕН>/setChatMenuButton?menu_button={"type":"web_app","text":"Блокнот","web_app":{"url":"https://<ваш-домен>"}}`

### 7. Таймер напоминаний
Бесплатный cron-job.org: задача `GET https://<ваш-домен>/cron/tick`, расписание «каждую минуту», в Advanced → Headers заголовок `X-Cron-Secret` со значением `CRON_SECRET`. Уведомления на почту при сбоях: «провален» после 5 запусков подряд. Cron Triggers Cloudflare не используются. Это около 1440 вызовов в сутки, около 1,5% бесплатного лимита Workers.

### 8. Первый вход
Откройте `t.me/<бот>?startapp`: приложение предложит познакомиться, затем в «Настройках» нажмите «Подключить бота» (разрешение боту писать вам). Дальше `/invite Имя` в боте даёт одноразовую ссылку для другого человека.

## Магазины
⚙️ Настройки → «🏪 Магазины»: готовый перечень из 19 сетей (основные продуктовые и универмаги Калифорнии и Техаса: Costco, Walmart, Target, WinCo Foods, Safeway, Vons, Ralphs, Albertsons, Trader Joe's, Sprouts, Stater Bros., H-E-B, Kroger, Tom Thumb, Sam's Club, и хозяйственные The Home Depot, Lowe's, Ace Hardware, Harbor Freight; перечень в `src/stores.js`, составлен по открытым источникам) и свои магазины.
- **Избранное = список покупок.** Звёздочка на магазине создаёт его список на вкладке «Покупки». Названия магазинов живут только через избранное: магазин, который вы назвали боту впервые, сам добавляется в «Магазины» как свой избранный, и список появляется автоматически.
- **Убрать магазин можно только с пустым списком** (купленное тоже считается, его надо очистить). Если в списке есть пункты, приложение предупреждает, и звёздочка остаётся. Пустой список исчезает вместе с магазином. Название магазина из перечня менять нельзя, свой переименовывается вместе со списком.
- **Бот узнаёт магазины по звучанию:** «Костко», «Костка» и «Costco» это один список. Известные русские написания узнаются всегда; избранные магазины узнаются снисходительно (даже при заметной ошибке в произношении), остальные строго (только точное или то же по звучанию, иначе создаётся новый магазин); при равенстве выигрывает избранный. Затем сравнение дополняет DeepSeek (ему передаются известные магазины).
- Новые написания бот запоминает сам (до 12 на магазин). Названия магазинов передаются Groq как подсказка для распознавания голоса. То же работает для `/buy Костко`, «покажи список для Костко» и «+ Магазин» в приложении.
- Старые списки покупок без магазина при первом открытии «Магазинов» или «Покупок» сами становятся избранными магазинами.

## Корзина
Удалённое не стирается сразу, а хранится 7 дней (`TRASH_DAYS` в `src/config.js`), потом удаляется окончательно (раз в сутки, вместе с остальной уборкой). В приложении: значок корзины вверху рядом с ⚙️. Он показывает состояние: пустая корзина (чёрные окошки) или полная (белые окошки и бумажки сверху); меняется сразу после удаления, возврата и очистки.
- В корзину попадают заметки, задачи и ссылки, **папки вместе с содержимым** и отдельные пункты покупок (✕ и «Очистить купленное»). Список магазина с пунктами удалить нельзя, поэтому в корзину он не попадает.
- В корзинной папке можно зайти, открыть любую заметку (просмотр без правки) и вернуть только её: она попадёт в «Разное». Папку можно вернуть целиком; если папка с таким названием уже есть, заметки из корзины добавляются в неё (было 2, вернули 5, стало 7). То же правило у списков покупок.
- Заметка, удалённая отдельно, возвращается в свою папку (если её уже нет, в «Разное»). Пункт покупок возвращается в свой список (если его нет, в «Без магазина»).
- Пока заметка в корзине, её напоминание не срабатывает и в календаре не видно. После возврата разовое напоминание с прошедшим временем отменяется, повторяющееся переносится на следующий срок.
- В боте под удалённой заметкой есть кнопка «Вернуть».
- Удаление человека целиком (`/remove`) окончательное, без корзины.

## Приватность и защита

- Тексты заметок и голос обрабатываются сервисами DeepSeek и Groq; людям об этом сообщается при знакомстве.
- Каждый запрос к данным содержит `user_id` из подписанных данных Telegram; чужие заметки, папки, напоминания и покупки недоступны. Это проверяет `npm run check:isolation` (44 проверки: изоляция двух людей, права админа, блокировка, подписанные ссылки `.ics`, секреты webhook и таймера, размер запроса).
- Webhook принимает только запросы с `X-Telegram-Bot-Api-Secret-Token`, таймер только с `X-Cron-Secret`.
- Ссылка на `.ics` подписана и живёт 10 минут (она открывается во внешнем браузере, где нет входа через Telegram).
- Заголовки: `Content-Security-Policy` (приложение можно встроить только в Telegram), `X-Content-Type-Options`, `Referrer-Policy`. Запросы больше 100 КБ отклоняются.
- Ключи только в секретах Worker'а; в репозитории их нет (`.dev.vars` в `.gitignore`).
- Ограничения: голосовое до 180 секунд, текст до 2000 знаков (`src/config.js`). Лимитов на количество заметок нет, расход контролирует админ блокировкой.
- Раз в сутки удаляются отправленные напоминания старше 90 дней и всё, что пролежало в корзине дольше 7 дней. Пока удалённое в корзине, оно остаётся в базе.

## Локальная разработка

1. `npm install`
2. Создайте `.dev.vars` с теми же именами, что в таблице секретов (значения любые для проверки без внешних сервисов).
3. `npm run db:migrate:local`, `npm run dev`.
4. `npm test` (автотесты логики), `npm run check:isolation` (проверка защиты на запущенном `npm run dev`), `npm run check:trash` (сквозная проверка корзины: папки, заметки, покупки, напоминания, объединение при возврате, срок хранения) и `npm run check:stores` (магазины: избранное, запрет удаления непустого списка, узнавание, переименование; в `.dev.vars` нужны DEEPSEEK_API_ROOT и TG_API_ROOT на http://127.0.0.1:8099; для неё в `.dev.vars` нужен `TG_API_ROOT=http://127.0.0.1:8099`, заглушку Telegram скрипт поднимает сам).

Вне Telegram приложение показывает просьбу открыть его через Telegram.

## Частые проблемы

- **`setWebhook` отвечает «404 Not Found».** Обычно в секрете есть недопустимые символы (допустимы только латиница, цифры, `_`, `-`) или в токене лишний пробел.
- **Бот молчит, в приложении «Не удалось войти».** Worker не видит секретов: они добавлены в раздел Build, а не Runtime, либо ещё не применились (подождите минуту). Токен в секрете должен совпадать с токеном бота.
- **Команда не срабатывает, бот записывает её как заметку.** Команду нужно набирать руками; вставленный из другого места текст Telegram оформляет как код, и командой он не считается.
- **Напоминание «через N минут» пришло на минуту позже.** Таймер срабатывает раз в минуту; срок округляется до ближайшей минуты, отклонение до 30 секунд. Для «в 9:00» срабатывает в 9:00.
- **Ключ DeepSeek или Groq не работает.** Бот сохранит сообщение как есть в «Разное» и сообщит, что обработать не удалось; голос в таком случае не сохраняется.
- **Секреты пропали после деплоя.** Проверьте, что в `wrangler.toml` есть `keep_vars = true`, и добавьте секреты заново.
