# Блокнот — Telegram-бот для заметок и напоминаний

Один Cloudflare Worker: Telegram-бот (webhook), веб-страница, таймер напоминаний. Доступ по приглашению.
Статус: **этап 5 из 6** (приглашения, Mini App, управление людьми, текстовые и голосовые заметки, напоминания, деление на заметки, список покупок, приложение с папками, заметками, календарём).

## Как это устроено
Приложение — Telegram Mini App: открывается внутри Telegram, Telegram сам сообщает, кто его открыл (подписанные данные `initData`), Worker проверяет подпись по токену бота. Паролей, cookie и ссылок входа нет.

- Приглашение: админ пишет боту `/invite` (или `/invite Олег` с подписью) и получает ссылку `t.me/<бот>?startapp=КОД`. Человек открывает её в Telegram, вводит имя, и ссылка гасится. Дальше он заходит кнопкой «Блокнот» в чате с ботом.
- Админ (ID из секрета `ADMIN_TELEGRAM_ID`) знакомится с приложением без приглашения.
- В приложении: тема (авто: следует за темой Telegram и меняется сразу / светлая / тёмная), часовой пояс (определяется браузером), кнопка «Подключить бота» (разрешение боту писать).
- Панель управления (только админ): в приложении удерживайте значок ⚙️ в шапке (сверху справа) 2 секунды (обычное нажатие открывает настройки). Там список людей (заблокировать, вернуть доступ, удалить) и приглашения (создать, отправить, отозвать).
- Команды админа в боте: `/invite`, `/revoke`, `/users`, `/block`, `/unblock`, `/remove`.

## Развёртывание с нуля
1. `npm install`
2. В @BotFather: `/newbot` (имя «Блокнот»), запомнить токен и username.
3. `npx wrangler d1 create notes_db` → `database_id` вписать в `wrangler.toml`; туда же `BOT_USERNAME` (без @).
4. `npm run db:migrate`
5. Секреты (`npx wrangler secret put ИМЯ`): `TG_BOT_TOKEN`, `TG_WEBHOOK_SECRET` (случайная строка), `CRON_SECRET` (случайная строка), `ADMIN_TELEGRAM_ID` (ID из @userinfobot). `DEEPSEEK_API_KEY` (нужен с этапа 2; модель `deepseek-flash`), `GROQ_API_KEY` (бесплатный ключ с console.groq.com, нужен с этапа 3; модель `whisper-large-v3-turbo`).
6. `npm run deploy` (домен notes.fixtorllc.com привязывается через `routes`).
7. Webhook, один раз:
   `curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook" -d url=https://notes.fixtorllc.com/tg/webhook -d secret_token=<TG_WEBHOOK_SECRET>`
8. В @BotFather: **Bot Settings → Configure Mini App → Enable Mini App**, адрес `https://notes.fixtorllc.com`. Это включает прямые ссылки `t.me/<бот>?startapp=...`.
9. Кнопка «Блокнот» в чате (один раз):
   `curl "https://api.telegram.org/bot<ТОКЕН>/setChatMenuButton" -H 'content-type: application/json' -d '{"menu_button":{"type":"web_app","text":"Блокнот","web_app":{"url":"https://notes.fixtorllc.com"}}}'`
10. Откройте `t.me/<бот>?startapp` у себя: приложение предложит познакомиться.

## Приложение (Mini App)
Нижняя панель: **Заметки** (папки, поиск по всем заметкам, создать/переименовать/удалить папку; удалённая папка отдаёт заметки в «Разное», саму «Разное» трогать нельзя), **Покупки** (общий список: нажатие отмечает купленное, купленные бледнеют, зачёркиваются и уходят вниз, «Очистить купленное»), **Календарь** (месяц с точками на днях с напоминаниями, повторы раскрываются по правилу, нажатие на день показывает список). Заметку можно править и переносить между папками. У напоминания: дата и время, повтор по дням недели галочками («каждую неделю» / «раз в N недели»), «Убрать», «В календарь (.ics)» (файл с событием и сигналом) и «В Google Календарь». Ссылка на .ics подписана и живёт 10 минут: она открывается во внешнем браузере, где нет входа через Telegram.

## Задачи, ссылки, «Входящие»
- **Задачи:** папка в виде списка дел. Невыполненные сверху, серая полоса «Выполненные · N», ниже выполненные (зачёркнутые, бледные). Кружок слева отмечает выполненное, ✕ удаляет.
- **Ссылки:** если прислать боту только ссылку (или несколько), она сохраняется в папку «Входящие» без запроса к DeepSeek. Под сообщением кнопки «Куда поместить», «Добавить комментарий» (следующее сообщение дописывается к ссылке, `/cancel` отменяет) и «Удалить». Если ссылка идёт с текстом («добавь https://… в мои приложения, комментарий …»), её разбирает DeepSeek: ссылка сохраняется без изменений, папка выбирается или создаётся.
- **Ежедневное напоминание:** пока во «Входящих» что-то лежит, раз в сутки после 12:00 по местному времени бот напоминает разобрать (кнопка открывает эту папку). Опустела папка, напоминания прекращаются. Время задаёт `DIGEST_HOUR` в `src/config.js`.
- «Задачи», «Разное», «Входящие» нельзя переименовать или удалить.
- В приложении адреса в заметках нажимаются (открываются в браузере).

## Деление на заметки и список покупок
Одно сообщение (текстом или голосом) DeepSeek делит на отдельные заметки (до 10), каждая со своей папкой и напоминанием, и отвечает на каждую отдельным сообщением с кнопками. Покупки из сообщения собираются в общий живой список покупок на человека: `/buy` показывает его кнопками (⬜ нужно купить, ✅ куплено, купленные внизу, «Очистить купленное»). Покупка со временем («завтра купить цветы») остаётся обычной заметкой с напоминанием.

## Напоминания и таймер
Бот понимает «завтра в 9», «через 3 минуты», «каждый понедельник и среду в 10:30», «раз в две недели по пятницам». Сработавшее напоминание приходит с кнопками «Готово», «Отложить на 1 час», «До завтра 9:00». `/reminders` показывает будущие.

Таймер: бесплатный cron-job.org раз в минуту вызывает `GET https://notes.fixtorllc.com/cron/tick` с заголовком `X-Cron-Secret: <значение секрета CRON_SECRET>` (в cron-job.org: Advanced → Headers). Cron Triggers Cloudflare не используются. Точность до минуты. Ответ `{"sent": N}`.

Миграции применяются при каждом деплое (команда деплоя: `npx wrangler d1 migrations apply notes_db --remote && npx wrangler deploy`).

## Локальная проверка
Секреты в `.dev.vars` (в git не попадает), `npm run db:migrate:local`, `npm run dev`, тесты: `npm test`. Вне Telegram приложение покажет просьбу открыть его через Telegram.
